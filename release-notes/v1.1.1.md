## Highlights

<!-- What a user notices in this release, in a few bullets. -->

- **Removed the experimental live delay mode.** It didn't work well enough to keep. The **View → SubSync → Experimental: no extra track (live delay)** item and the `sync_mode=` setting are gone, and SubSync always adds the synced subtitles as a new track (the default all along). If you had it on, there is nothing to do: an old `sync_mode=` line in `config.ini` is ignored.

## Install or upgrade

You need [VLC 3](https://www.videolan.org/vlc/). Close VLC, then:

**Linux / macOS**: paste in a terminal:

```sh
curl -LsSf https://github.com/sergimn/VLCSubtitleSync/releases/download/v1.1.1/install.sh | sh
```

**Windows**: download `install.cmd` below and double-click it.

Then restart VLC. Running the installer again upgrades an existing install.
