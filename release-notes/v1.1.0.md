## Highlights

<!-- What a user notices in this release, in a few bullets. -->

SubSync is quieter and starts smarter.

- **Only problems on screen.** SubSync no longer puts "Syncing subtitles…", progress and "Subtitles synced" messages in VLC's top-right corner. It only shows a message when something goes wrong, such as *"SubSync: not synced (… too few transcript matches …) – keeping original timing"*. To see everything again, turn on **View → SubSync → Show all messages**. The setting is remembered, and the Status window shows which one is active.
- **A short wait before syncing a newly opened file.** For the first 10 seconds after you open a file, SubSync doesn't start transcribing, so picking a different audio or subtitle track right away no longer wastes a sync on VLC's default pair. Changing a track yourself ends the wait at once, a file you already synced gets its synced subtitles straight from the cache, and **Sync subtitles now** never waits.

## Install or upgrade

You need [VLC 3](https://www.videolan.org/vlc/). Close VLC, then:

**Linux / macOS**: paste in a terminal:

```sh
curl -LsSf https://github.com/sergimn/VLCSubtitleSync/releases/download/v1.1.0/install.sh | sh
```

**Windows**: download `install.cmd` below and double-click it.

Then restart VLC. Running the installer again upgrades an existing install.
