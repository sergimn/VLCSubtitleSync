## Highlights

<!-- What a user notices in this release, in a few bullets. -->

First release. SubSync makes VLC re-time your subtitles to the audio automatically: pick a subtitle track, keep watching, and a few seconds later it is swapped for a synced copy.

- Fixes constant delays, drift (25 fps subtitles on 23.976 fps video, or 29.97 fps TV subtitles that drift by 25%) and cuts (a subtitle made for a version with an extra scene or ad break).
- Uses OpenAI's Whisper speech model locally on your computer, offline after the first download. No account, no upload.
- Results are cached, so reopening a file is instant. **View → SubSync** can force a re-sync, run an exhaustive sync for hard files, or turn auto-sync off.
- The installer finds every VLC (system package, snap, flatpak, macOS app, Windows) and shows SubSync with its icon in VLC's Addons Manager. The helper starts with VLC and quits after it; nothing runs at login.
- Experimental, off by default: correct the selected subtitle track with a live delay instead of adding a synced copy.

## Install or upgrade

You need [VLC 3](https://www.videolan.org/vlc/). Close VLC, then:

**Linux / macOS**: paste in a terminal:

```sh
curl -LsSf https://github.com/sergimn/VLCSubtitleSync/releases/download/v1.0.0/install.sh | sh
```

**Windows**: download `install.cmd` below and double-click it.

Then restart VLC. Running the installer again upgrades an existing install.
