## Highlights

<!-- What a user notices in this release, in a few bullets. -->

- **Subtitle files you add yourself now sync too.** SubSync now finds a file added with **Subtitle → Add Subtitle File…** or dropped onto VLC, and files not named like the video. If it can't be sure which file VLC loaded (for example, two files added by hand), it stops with *"Can't tell which file subtitle track … is"* rather than syncing the wrong one. On Windows, a file added by hand has to be in the video's folder or its `Subs` folder.
- **Mixed-language audio now syncs.** SubSync checks the spoken language at up to five points in the video instead of one, so a film with some foreign dialogue still gets a full sync.
- **Installs use the tested library versions.** The installer now installs the exact library versions each release was tested with. If you install the `vlc-subsync` package yourself, it now needs Python 3.12 or newer.

## Install or upgrade

You need [VLC 3](https://www.videolan.org/vlc/). Close VLC, then:

**Linux / macOS**: paste in a terminal:

```sh
curl -LsSf https://github.com/sergimn/VLCSubtitleSync/releases/download/v1.2.0/install.sh | sh
```

**Windows**: download `install.cmd` below and double-click it.

Then restart VLC. Running the installer again upgrades an existing install.
