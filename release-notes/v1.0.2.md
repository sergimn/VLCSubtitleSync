## Highlights

<!-- What a user notices in this release, in a few bullets. -->

A Windows installer fix. Linux and macOS installs are unchanged.

- **Windows 11 with Smart App Control (or a company App Control policy).** The 1.0.1 installer stopped at "Configuring VLC" with "An Application Control policy has blocked this file". Windows blocked the small `vlc-subsync.exe` launcher that the installer creates on each PC, because it had never seen that file. The installer, and VLC when it starts SubSync's helper, now run SubSync through its Python instead, which Windows recognises. If Windows still blocks the `vlc-subsync` command in a terminal, the installer says so and prints the command to use instead.
- **No more silent wait after installing.** The installer now says when it is checking that the speech engine loads. If the check takes a while, which can happen the first time while Windows or antivirus scans the new files, it explains the wait. After 5 minutes it stops with a clear error instead of waiting forever.

If the 1.0.1 installer failed or hung on your Windows PC, run the 1.0.2 installer again.

## Install or upgrade

You need [VLC 3](https://www.videolan.org/vlc/). Close VLC, then:

**Linux / macOS**: paste in a terminal:

```sh
curl -LsSf https://github.com/sergimn/VLCSubtitleSync/releases/download/v1.0.2/install.sh | sh
```

**Windows**: download `install.cmd` below and double-click it.

Then restart VLC. Running the installer again upgrades an existing install.
