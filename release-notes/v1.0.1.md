## Highlights

<!-- What a user notices in this release, in a few bullets. -->

A Windows installer fix. If SubSync 1.0.0 is already working for you, there is nothing new here.

- **Windows PCs without the Microsoft Visual C++ runtime.** With 1.0.0 the installer said "Finished successfully", but the speech engine could not load, so subtitles were never synced. The installer now checks that the engine loads, adds the Visual C++ runtime if it is missing (Windows asks once for permission), and stops with a clear error if the engine still can't load. Most PCs already have this runtime, since many apps install it.
- **Windows on ARM laptops** (Snapdragon and others) are now supported. The 1.0.0 install failed there. SubSync now uses x64 Python, which Windows runs under emulation.
- Running `install.cmd` from a PowerShell 7 window no longer fails with "module could not be loaded".

If 1.0.0 didn't sync anything on your Windows PC, run the 1.0.1 installer again.

## Install or upgrade

You need [VLC 3](https://www.videolan.org/vlc/). Close VLC, then:

**Linux / macOS**: paste in a terminal:

```sh
curl -LsSf https://github.com/sergimn/VLCSubtitleSync/releases/download/v1.0.1/install.sh | sh
```

**Windows**: download `install.cmd` below and double-click it.

Then restart VLC. Running the installer again upgrades an existing install.
